## 1. Что делали в этой сессии (кратко)
- ПЕРЕДЕЛАНО по правке пользователя (скриншот): координаты больше НЕ самодельная
  строка в DOM-редакторе — это НАТИВНЫЕ опции ноды `center_x` / `center_y`
  (INT, шаг 1, диапазон со знаком), стоят сразу под виджетом «Фиксация пропорций»
  и выглядят как остальные бегунки (label + `−` + значение + `+`); подписи — в
  `locales/{ru,en}/nodeDefs.json` («Центр рамки X/Y»);
- кнопка «?» перенесена из бара кнопок в ПРАВЫЙ ВЕРХНИЙ УГОЛ ПРЕВЬЮ
  (внутри `.degg-crop__stage`, как в `Degg_Images_Save_Compare`); сама подсказка
  осталась в корне (сцена режет содержимое), позиция — через `syncHelpAnchor()`;
- добавлен `tests/_shot_live_node.py` — снимок живого узла PNG в headless Chrome
  (визуальная проверка глазами).
- Новая семантика «Зафиксировано» (`lock_ratio`): фиксирует ТЕКУЩИЕ пропорции
  рамки (`state.ratioLock = currentPxRatio()`), а не пресет из списка; выбор
  пресета применяет его И включает замок; «Свободные» снимают замок.
- Секция координат под баром: два числовых поля X/Y — смещение ЦЕНТРА РАМКИ
  относительно центра изображения, в ПИКСЕЛЯХ оригинала (единицы подтверждены
  пользователем). Ввод двигает рамку, изменение рамки перезаписывает поля.
- Shift-модификаторы в режиме «Свободно»: Shift+перетаскивание внутри = строго
  одна ось (`axisDelta`); Shift+край/угол = ресайз с сохранением текущих
  пропорций (`state.drag.ratio`), замок при этом НЕ включается.
- Иконка «?» с подсказкой (RU/EN) — по образцу `Degg_Images_Save_Compare`
  (`helpBox` + `LABELS.help`, открытие по клику/наведению).
- Найден и починен баг «разгона» рамки при drag: масштаб и смещение сцены
  теперь фиксируются на `pointerdown` (`state.drag.view`) — иначе рост рамки
  расширяет union → меняет scale → следующий pointermove считает дельту по
  новому масштабу (рамка улетала в долю сцены 88 и теряла пропорции).
- Спека §5/§7 обновлена (в т.ч. новый DRAG-ИНВАРИАНТ и список мутаций).

## 3. Проблемы, которые встречались (и как решали)
- Ложное «пропорция не 16:9» в живой пробе: сравнивался пиксельный `frameBox`
  (округление до целых CSS-пикселей → 2×2 при сжатой сцене). Теперь пропорция
  считается по `frac` (точные доли) × natural.
- Ложное «координаты не те»: ожидание считалось от картинки 1000×500, а в ComfyUI
  768×768 → ожидание пересчитывается от `natural`.
- Ложное «Shift не держит ось»: при маленькой рамке центр кадра попадал в зону
  захвата края (EDGE_HIT 12 px) → для перемещения взята рамка 0.8×0.6.
- Разгон рамки (см. §1) — лечится фиксацией `state.drag.view`.
- Реентерабельность: программная запись виджета вызывала callback → цикл;
  введён `state.suppress` + `programmatic(widget, value)`.
- Мутации детекторов (все дали RED, файлы восстановлены):
  `state.ratioLock = 1` → проба «Зафиксировано держит захваченные пропорции при
  ресайзе»; `axisDelta` без оси → «Shift держит одну ось»; `state.drag.ratio →
  null` → «Shift + край сохраняет пропорции»; `sourceFromLocal(localFromEvent(event))`
  → «drag не разгоняет рамку» (доля 88) + аудит (2 FAIL).
- Bash heredoc с длинным python-кодом рвётся («unterminated triple-quoted
  string literal») → писать патч-скрипт файлом в
  `C:\Users\dggio\AppData\Local\Temp\opencode\` и запускать `python <path>`.

## 4. Что важно не сломать при продолжении работы
- Координаты — ТОЛЬКО нативные виджеты `center_x`/`center_y` под «Фиксацией
  пропорций»; самодельной строки в DOM-редакторе больше нет (аудит это держит).
- Писать координаты ТИХО (`setWidgetValueQuiet`): громкая запись через callback
  перезапускает ноду на каждом кадре drag'а.
- Кнопка «?» — внутри `stage` (правый верхний угол превью), подсказка — в корне.
- Правка координат обязана двигать рамку (callback → `applyCoords`).
- «Сбросить» НЕ вызывает `applyAspect` и НЕ меняет настройки результата.
- «По центру» никогда не масштабирует; «Вписать» масштабирует равномерно.
- Захват пропорций в замке — ТЕКУЩИЕ пропорции рамки, не пресет.
- Единицы координат — ПИКСЕЛИ оригинала (смещение центра рамки от центра
  изображения), не доли и не проценты.
- Значения COMBO — протокол; переводы только через `getOptionLabel`.
- Язык переключается без F5/рестарта; слушатель снимается в `onRemoved`.
- DRAG-ИНВАРИАНТ: `state.drag.view` нельзя убирать — без него рамка разгоняется
  (проверено мутацией, аудит держит детектор).
- `sync.py` после правок; Python-правка = рестарт ComfyUI, JS — `Ctrl+Shift+R`.
- Запрещены: `setInterval`/`MutationObserver`/`visibilitychange`, глобальные
  `window`-слушатели, `options.disabled`, `scripts/app.js`, canvas-рисование.
