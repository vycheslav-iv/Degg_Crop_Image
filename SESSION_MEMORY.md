## 1. Что делали в этой сессии

1. **Режим «файл из input» без подключённого сокета** (`2f19c76`): сокет `image`
   стал необязательным, добавлен комбо `image_file` (файлы папки `input`),
   сервер читает файл (PIL) и берёт из альфы маску; приоритет — у сокета.
2. **Файл — наверх, кнопка загрузки** (`840cc1e`): `image_file` + своя кнопка
   «Загрузить файл» (нативный виджет-кнопка, `POST /upload/image`) — в самом
   верху ноды, над кнопками «Вписать / По центру / Сбросить».
3. Попутно исправлены три реальных бага: upstream искался по индексу сокета 0;
   размер DOM-виджета задавался поздним override `computeLayoutSize` (фронтенд
   считает `hasLayoutSize` при первом рендере); новый виджет сдвигал
   позиционное восстановление значений в старых воркфлоу.
4. **Штатный Mask Editor на ноде** (решение открытого вопроса): без своих
   кнопок — нода отдаёт фронтенду `node.imgs`, и фронтенд показывает штатные
   точки входа (пункт «Open in MaskEditor» в контекстном меню, кнопка маски в
   панели выбора, команда в палитре). Результат рисования сохраняется на
   сервер, применяется к результату и виден в превью.
5. **Интерфейс приведён к виду Nodes 2.0** (по правке пользователя): убраны
   свои кнопки «Маска» и «Загрузить файл» в Vue-режиме — загрузка идёт
   штатной иконкой-папкой в комбо, маска — штатными точками входа.

## 3. Проблемы, которые встречались (и как решали)

- **Размер по долям, а не по пикселям** (1448×1448 вместо 1928×1088) — размер
  результата считается по пикселям кадра; проверки пропорций обязаны брать
  НЕКВАДРАТНЫЙ источник (`example.png` = 768×768 ничего не доказывает).
- **Чёрный выход при подключённой маске** — маска = 1 там, где убрать; старая
  заглушка 64×64 трактовалась как «скрыть всё».
- **Позиционное восстановление значений** — фронтенд восстанавливает по
  позициям; нода чинит это восстановлением по именам (`widgets_values_named`).
- **`required_input_missing`** — ComfyUI требует все обязательные входы; API
  чистый ⇒ обязательны только значимые (`megapixels`, `multiplicity`,
  `resample`, `fill`, `dim_outside`), остальные — optional. Вход без параметра
  в сигнатуре `crop()` роняет ноду (защищено тестом).
- **Комбо-файл нельзя делать обязательным** — сервер проверяет значение комбо по
  списку: обязательный вход заставил бы API подставлять имя файла, а без
  файлов в `input` нода не запустилась бы. Отсюда `image_file` = optional.
- **`hasLayoutSize`** — фронтенд считает признак «растягиваемый виджет» при
  ПЕРВОМ рендере; поздний override `computeLayoutSize` не учитывается ⇒
  строка сетки остаётся `min-content` и превью не растёт с нодой. Лечение:
  `getMinHeight` в опциях `addDOMWidget`.
- **Превью перестало расти с нодой после правок** — оказалось, что ломает не
  код, а сама проба: нода увеличена, а проверка ресайзила её в меньшую
  сторону. Диагностика: `tests/_diag_layout_crop_image.py`.

## 4. Что важно не сломать при продолжении работы

- ⛔ **Мегапиксели затираются при смене картинки** — следствие решения
  «значения ноды = значения изображения» (SPEC §8.1). Не менять без решения
  пользователя.
- ⛔ **Шесть видимых входов сервер не читает** (`aspect_ratio`, `lock_ratio`,
  `center_x/y`, `frame_w/h`) — это элементы управления редактора; состояние в
  `crop_rect`/`output_size`. Переработка контракта НЕ делается (SPEC §8.2).
- ⛔ **Батч: размер результата считается от первого кадра** (SPEC §8.3).
- ⛔ **Размер результата в UI и в API считается по-разному** (SPEC §8.5) —
  решение пользователя «оставить как есть».
- ⛔ **Маска** — конвенция ComfyUI (1 = убрать, видимая альфа = 1 − маска)
  НЕ МЕНЯТЬ. У файла, сохранённого Mask Editor, альфа = инвертированная маска
  (`applyMaskAsAlpha`: 255 − маска) ⇒ маска = 1 − альфа (SPEC §9.4).
- ⛔ Не добавлять свои кнопки «Маска»/«Загрузить файл» в Nodes 2.0: у
  стандартных нод загрузка — иконка-папка в комбо, маска — штатные пункты
  фронтенда (контекстное меню «Open in MaskEditor», кнопка в панели выбора,
  палитра команд). Своя кнопка загрузки допустима только в legacy-режиме
  (`surfaces.vueNode: 'never'`).
- Правила фронтенда Nodes 2.0: `getMinHeight` вместо позднего override
  `computeLayoutSize`; upstream — по имени сокета; `hideInPanel` для
  DOM-виджетов, скрытых в панели; никаких `setInterval`/`MutationObserver` для
  layout.
- `sync.py` копирует ВСЕ `.py` из папки проекта (включая временные `_tmp_*.py`)
  → удалять их перед синхронизацией.
- Коммит-msg-хук (`_process/hooks` → `.githooks`) отклоняет сообщения, где
  назван файл, которого нет в diff.
