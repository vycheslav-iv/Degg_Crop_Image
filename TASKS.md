- Новая работа → новая строка `T-N`, статус `NOT STARTED`.
- Закрыл → `DONE` + в «Чем закрыта» тест/команда/коммит с прогоном проверки.
- Застрял → `BLOCKED` + причина прямо в задаче; бросил намеренно → `CANCELLED`.
- Проверка краснеет, если статус не из словаря или у `DONE` нет артефакта:
  `python _process/check.py Degg_Crop_Image`.
